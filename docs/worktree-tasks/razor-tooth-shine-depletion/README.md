## 计划

- 用真实出牌复现最后 1 点闪耀被剃刀牙升级回满、永久原牌残留。
- 修正 Core 的升级回满入口，完成定向回归并同步本地目标分支。

## 结果

Core 扣除最后 1 点闪耀时先回写永久原牌，再标记战斗副本待耗尽。剃刀牙随后升级战斗副本，升级后的通用回满会清除待耗尽标记，导致结算收尾跳过归档及移除，原牌以 0/6 留在永久牌组。

在 `ShineService.UpgradePatch` 保护待耗尽状态。该次原生升级仍可执行，自动回满跳过已经待耗尽的卡牌，现有批次收尾负责移除并归档一次。闪耀尚未耗尽的升级继续回满。此修复在新的出牌结算中生效，已有的闪耀 0 残留需要单独进行存档恢复。
