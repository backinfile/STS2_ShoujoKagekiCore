# 闪耀存档修复发行升版

## 用户要求

> 合并提交推送，然后做发布前全面测试

> 提升版本号吧

## 计划

将 Core 的发行版本升到 2.0.3，与 Karen v1.0.3 配套。构建三个游戏目标，验证新旧 Core 共存时加载修正后的发行包。原检出中的巡检文档改动保留在原检出。

## 结果

- 发行清单、程序集构建默认版本和发布命令更新为 2.0.3。构建 v0.107.1、v0.111.1、v0.113.0 三个目标，并严格校验独立 Core 包。引导基础检查 34 项通过。
- 使用实际 2.0.2 和 2.0.3 包在四个游戏版本各择版 128 次，512 次均选择 2.0.3。各版本均拒绝用单独的 2.0.2 满足 Karen 的新最低依赖。
- v0.113.0 同时安装两个 Core 和 Karen v1.0.3，关闭 BaseLib 玩家 JSON 扩展后写盘并重启。两个进程均加载 Core 2.0.3，闪耀耗尽档案和可见牌堆续玩通过。
- 候选包与定向证据归档至 <Karen 仓库> 的 artifacts/task-deliverables/shine-release-version-20261123/。
